# Field BackUp

Aplicación de escritorio para Windows que hace backups automáticos de
carpetas. Corre en la bandeja del sistema, se programa con horarios o
intervalos, y guarda un historial de cada corrida.

## Descarga

La última versión está siempre en la sección
**[Releases](../../releases/latest)**: bajate `FieldBackUp.exe` y ejecutalo,
no requiere instalación.

Junto al ejecutable se publica un archivo `FieldBackUp.exe.sha256` con la
suma de verificación SHA256, para poder comprobar que la descarga llegó
íntegra.

## Actualizaciones

El programa se actualiza solo: chequea si hay una versión nueva al
arrancar, cada 6 horas, y cuando apretás el botón **Buscar
actualizaciones**. Si encuentra una, te pide confirmación antes de
descargarla e instalarla.
